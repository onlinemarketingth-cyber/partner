# CI-002: GENESENN Brand Palette — Adoption Notes

- **Date:** 2026-07-08
- **Source:** GENESENN logo (co-brand partner — see CLAUDE.md title:
  "Sync Vision Agent (Thai Life × GENESENN)"), image supplied directly
  by the human in chat.
- **Status:** Accepted, project-wide (human-approved, supersedes the
  color half of CI-001).

## What changed

CI-001 (Neural Atlas reference) picked **indigo** as the primary
accent and **lime** as a secondary accent reserved for gamification —
both were placeholder choices sourced from an unrelated Dribbble
mockup, not from either partner company's actual brand. GENESENN is a
named co-owner of this project, so its real logo colors take
precedence. Human decision (2026-07-08): replace indigo → **brand**
(navy) and lime → **gold**, **project-wide**, with gold fully taking
over lime's old "gamification/success" role (no dual-accent split).

CI-001's other decisions are unaffected: shape language stays
`rounded-xl`/`rounded-2xl` app-wide (`rounded-full` only on the Login
screen, per its own addendum), and the dot-grid logo mark / editorial
headline treatment are unchanged in structure — only their color
values moved from indigo/lime to brand/gold.

## Color values

Sampled visually from the supplied GENESENN logo image (no direct
pixel access in this environment — treat as best-effort estimates, not
an exact brand-guideline extraction; ask GENESENN/marketing for an
official hex spec if pixel-perfect accuracy is ever required):

- **Brand (navy)** — anchor `#1E2A54` at the `600` step (the ring/
  wordmark color in the logo).
- **Gold** — anchor `#A8875A` at the `400` step (the small filled dot
  in the logo's "C" gap).

Full 10-step Tailwind-style ramps (`tailwind.config.js` → `theme.extend.colors`),
generated by holding hue/saturation constant and interpolating
lightness from near-white (50) through the anchor step to near-black
(900):

| Step | brand | gold |

| 50 | `#F4F5FB` | `#FAF8F5` |
| 100 | `#C5CDEA` | `#E5DCCE` |
| 200 | `#96A5DA` | `#D1BFA7` |
| 300 | `#677DC9` | `#BCA381` |
| 400 | `#3F59B2` | `#A8875A` ← anchor |
| 500 | `#2F4183` | `#8C704A` |
| 600 | `#1E2A54` ← anchor | `#705A3B` |
| 700 | `#182142` | `#54432C` |

## Where it's used

Renamed `indigo-*` → `brand-*` and `lime-*` → `gold-*` across every
component that referenced them:

- `AppLogo.vue` — icon background (`brand-600`), dot-grid mark
  (`gold-400`), wordmark "Agent" text (`brand-600`).
- `TopNavigation.vue` — active nav state, font-size toggle, lang
  toggle, avatar badge.
- `TabFilterBar.vue` — `accentMap` keys `indigo`→`brand`,
  `lime`→`gold` (gold keeps the gamification/success-only usage note).
- `HeroHeader.vue` — default `iconColor`.
- `ConfirmDialog.vue` — `primary` variant.
- `HomeView.vue` — `accent-color` prop values.
- `LoginView.vue` — submit button, focus rings, lang toggle, checkbox
  accent (shape/layout from CI-001 addenda unchanged, only color).

## Not changed

- `gray` and the pre-existing unused `navy` key (a different, muted
  blue-gray — `#3F6C92`/`#325675` — ported earlier from medical-saas,
  not used anywhere in `src/`) are untouched; the new palette uses the
  name **`brand`** specifically to avoid colliding with that leftover
  `navy` key.
- `src/assets/base.css`'s `--vt-c-indigo` variable is unrelated
  boilerplate from the default Vue scaffold (`create-vue` theme), not
  part of our design system — left alone.
