## 2. บั๊กที่เจอ — 3 ตัว แก้สำเร็จทั้ง 3

**ทั้ง 3 ตัวเทสต์อัตโนมัติจับไม่ได้เลย** เพราะเป็นเรื่องที่ต้องเห็นหน้าจอถึงจะรู้

### บั๊ก #1 — หน้าสมัครโกหกคนที่กดลิงก์เข้ามา

เปิด `/c/qa-uat-2569` แล้วขึ้น **"ขั้นตอน 2 จาก 2"** คร่อมข้อความ **"กรอกรหัสเชิญของบริษัทเพื่อเริ่มสมัคร"**
— บนหน้าจอที่**ไม่มีช่องกรอกรหัส และกลับไปขั้นที่ 1 ไม่ได้** และปุ่ม "เปลี่ยนรหัส" ทั้งที่เขาไม่เคยพิมพ์รหัส

โค้ดเดิมกันสองอย่างนี้ไว้ให้เส้นทาง `?ref=` แล้วพร้อมคอมเมนต์อธิบายเหตุผลไว้ชัด — **ลิงก์บริษัทคือสถานการณ์เดียวกันเป๊ะ แต่ผมไม่ได้ครอบถึง**

**แก้:** เพิ่ม `viaCompanyLink` / `arrivedViaLink` · ปุ่มเปลี่ยนเป็น "ไม่ใช่บริษัทนี้?" · **ยืนยันบนหน้าจอแล้ว** + เทสต์ 2 ตัว

### บั๊ก #2 — ลิงก์ที่ย่อแล้วพาไปหน้าว่าง

**#2a** `/in/qa-test-co` → **ไม่มี route ใน SPA** และแอปนี้ไม่มี catch-all → เรนเดอร์กรอบแอปโดยข้างในว่าง
อ่านว่า "เว็บพัง" ไม่ใช่ "ลิงก์ผิด" (ไฟล์ `redirects.spec.ts` ของโปรเจกต์เตือนเรื่องนี้ไว้แล้ว)

**#2b** ระหว่างแก้ #2a เจอว่า **ลิงก์สื่อการขายผิดแบบเดียวกัน** — มันเสิร์ฟจาก **API** ไม่ใช่ SPA
แต่ผมสร้าง URL จาก origin ของ SPA → ชี้ไปที่ route ที่ไม่มีอยู่

**แก้:** `TrackedLinkGroup::resolvesOnFrontend()` เลือก origin ตามกลุ่ม · route `/in/:code` + `CompanyLoginLinkView` · endpoint `GET /public/login-links/{code}`

### บั๊ก #3 — กด "แชร์" แล้วยังได้ลิงก์ยาว 64 ตัว

`ProductShareLinkService::create()` เป็น idempotent (ใช้ลิงก์เดิมซ้ำ) และผมวางโค้ดสร้างรหัสสั้นไว้ **หลัง** early return

ผลคือ **รหัสสั้นเกิดเฉพาะกับสินค้าที่ไม่เคยแชร์มาก่อน** — ซึ่งบนฐานข้อมูลจริงคือกรณีที่เกิดน้อยที่สุด
ลิงก์ที่มีอยู่แล้วทุกอันจะไม่มีวันได้รหัสสั้นเลย โดยไม่มีอะไรอธิบายว่าทำไม

**แก้:** สร้างรหัสสั้นบนเส้นทาง reuse ด้วย + เทสต์ 1 ตัว

> **ผลข้างเคียงที่ดีขึ้นกว่าที่เขียนไว้ในเอกสารเดิม:** ตอนนี้พอตัวแทนกดแชร์อีกครั้ง — จังหวะที่เขากำลังจะส่งลิงก์ให้ใครพอดี — ลิงก์เก่าจะได้รหัสสั้นทันที โดยลิงก์ยาวเดิมยังใช้ได้เหมือนเดิม

## 3. แก้ไม่สำเร็จ — **ไม่มี**

บั๊กทั้ง 3 แก้แล้วและยืนยันแล้ว ไม่มีอะไรค้างในสภาพพัง

**แต่มีเรื่องกระบวนการที่ผิดพลาด 1 ครั้งและควรบันทึกไว้:** ตอนแก้บั๊ก #1 ผมแก้ไฟล์ใน**สำเนาบนคลาวด์ของผมเอง**
แล้วรีเฟรชเบราว์เซอร์ทันที ซึ่งยังเป็นไฟล์เดิมของเครื่อง human อยู่ — หน้าจอไม่เปลี่ยน
ต้องส่งไฟล์กลับเข้าเครื่องก่อนถึงจะเห็นผล **เสียไป 1 รอบเพราะผมลืมว่าเบราว์เซอร์อ่านดิสก์ของ human ไม่ใช่ของผม**

## 4. ⚠️ สิ่งที่ยัง "ไม่ผ่าน" ในความหมายว่า **ยังไม่ได้พิสูจน์**

### 4.1 Conversion — ยังไม่เคยเห็นเลขขึ้นจาก 0 เลยสักครั้ง

**นี่คือช่องว่างที่ใหญ่ที่สุดของ UAT รอบนี้** ทุกหน้าจอแสดง "ผลลัพธ์ 0" ตลอด
เพราะไม่มีใคร**สมัครจริง**หรือ**สั่งซื้อจริง**ผ่านลิงก์ที่ทดสอบ

แปลว่าครึ่งหลังของฟีเจอร์ — `tracked_link_id` บน `users`/`orders`/`referrals`, ตัวนับ conversion,
อัตราแปลง, อันดับ "ตัวแทนที่ลิงก์ได้ผลมากที่สุด" — **ยืนยันด้วยเทสต์อัตโนมัติเท่านั้น ยังไม่เคยเห็นทำงานจริง**

### 4.2 `/in/` — พิสูจน์ได้แค่ครึ่งเดียว

ยิง API ตรง ๆ แล้วได้ `{"company_slug":"qa-test-co"}` (200) และรหัสมั่ว → 404 ✅

**แต่ยังไม่ได้เห็นหน้า login แบบมีธีมด้วยตา** เพราะเบราว์เซอร์นี้มี session ค้างอยู่ กด `/in/` แล้วเด้งเข้าหน้าแรกเลย
และเส้นทาง "สำเร็จ" กับ "ล้มเหลว" ต่างก็ไปที่ `/login` เหมือนกัน — ถ้าดูแค่หน้าจอจะแยกไม่ออก
**ต้องเปิดในหน้าต่าง incognito ถึงจะพิสูจน์ครบ**

### 4.3 บั๊ก #2b (สื่อการขาย) — แก้แล้วแต่ไม่เคยคลิก

เจอจากการอ่านโค้ด ไม่ใช่จากการคลิก และยังไม่ได้เปิดลิงก์สื่อการขายจริงสักครั้ง

## 5. ทำไม 4 กลุ่มที่เหลือถึงไม่ได้ทดสอบ

| กลุ่ม | เหตุผล |
|---|---|
| **สมัครลูกทีม `/j/`** | ต้องเป็น **หัวหน้าทีม** (`is_team_leader`) ถึงจะสร้างลิงก์ได้ (ADR-025 §1) บัญชีที่ล็อกอินค้างอยู่ไม่ใช่ ต้องให้แอดมินติดธงให้ก่อน |
| **แชร์ชำระเงิน `/pay/`** | ลิงก์เกิดพร้อม**ออเดอร์จริง** ต้องไล่สร้าง referral → order ซึ่งแตะข้อมูลการขายจริงในฐานข้อมูล |
| **ลิงก์พันธมิตร `/l/`** | ต้องผ่าน BR-1 (Basic) และไปสร้างที่หน้า "ลิงก์พันธมิตร" — ทำได้แต่ยังไม่ได้ทำ |
| **สื่อการขาย `/m/`** | ต้องมีไฟล์สื่อการขายในสินค้าและสร้างลิงก์จากหน้าแอดมิน |

**ทั้ง 4 กลุ่มใช้ `TrackedLinkService` ตัวเดียวกับที่ผ่านแล้ว** — แกนกลาง (สร้างรหัส, resolve, นับ, ลิงก์เก่ายังใช้ได้)
ถูกพิสูจน์บนหน้าจอแล้วผ่านกลุ่ม 1/3/7 **แต่นั่นเป็นเหตุผลว่าทำไมความเสี่ยงต่ำ ไม่ใช่ข้ออ้างว่าทดสอบแล้ว**
บั๊กทั้ง 3 ที่เจอวันนี้อยู่ที่ **ขอบของแต่ละกลุ่ม** ไม่ใช่ที่แกนกลาง — และนั่นคือส่วนที่ยังไม่ได้ดูของอีก 4 กลุ่ม
