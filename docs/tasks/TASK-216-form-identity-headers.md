# TASK-216 — ทุกฟอร์มแก้ไขต้องบอกว่ากำลังแก้ "ตัวไหน"

**Status:** implemented + verified in browser (2026-08-20) · **Owner:** ag-lead
**คำขอ:** human — "ผมขอปรับ แก้ไข Modal ทั้งหมดพร้อมชื่อสินค้า แบบนี้ผมดูไม่ออกเลยว่าผมกำลังแก้ไขตัวไหนอยู่"

---

## 1. ปัญหา

ฟอร์มแก้ไขในหน้า **แผนคอมมิชชั่น** เปิดขึ้นแบบ **inline ที่ด้านบนของหน้า**
แต่แถวที่กด "แก้ไข" อาจอยู่ห่างลงไปหลายแถวและเลื่อนพ้นจอไปแล้ว

และฟอร์ม **อัตราค่าคอมตัวแทนผู้ขาย** — ตัวที่อยู่ในสกรีนช็อตของคุณ —
**ไม่มีหัวข้ออะไรเลย** เปิดมาเป็นแถวช่องกรอกเปล่า ๆ เบาะแสเดียวว่ากำลังจะ
เขียนทับกฎใบไหนใน 6 ใบ คือชื่อสินค้าที่ฝังอยู่ใน `<select>` ซึ่งหน้าตา
เหมือนกับตอนกด "เพิ่ม" ทุกประการ

## 2. แก้อะไร

เพิ่มหัวข้อ 2 บรรทัดให้ทุกฟอร์มที่แก้ไข "รายการหนึ่งในหลายรายการ":

```
แก้ไขอัตราค่าคอมตัวแทนผู้ขาย          ← ทำอะไรอยู่
สินค้า: Vital Blueprint Mini + BALANZ V5 Health Tracker   ← กับตัวไหน
```

| ฟอร์ม | เดิม | ใหม่ |
|---|---|---|
| **อัตราตัวแทนผู้ขาย** (แผนคอมมิชชั่น) | **ไม่มีหัวข้อเลย** | เพิ่ม/แก้ไข + ชื่อขอบเขต |
| **อัตราหัวหน้าทีม** | มีหัวข้อ แต่ไม่บอกว่าใบไหน | + ชื่อขอบเขต |
| **อัตรารายชั้น (Matrix)** | ไม่มีหัวข้อ | + "ชั้นที่ N" |
| **ขั้นอันดับ (Stairstep)** | ไม่มีหัวข้อ | + "อันดับ: ชื่อ" |
| **อัตราราย Generation** | ไม่มีหัวข้อ | + "Generation ที่ N" |
| **Promotion** (หน้า Promotion) | "แก้ไข Promotion" เฉย ๆ | + ชื่อ Promotion |

**อ่านค่าจากฟอร์ม ไม่ใช่จากเรคคอร์ด** — ตั้งใจ เพราะทำให้มีประโยชน์ตอน
**สร้างใหม่**ด้วย: พอเลือกสินค้าปุ๊บ หัวข้อจะบอกชื่อทันที ถ้าเลือกผิดจะเห็น
**ก่อนกดบันทึก** ไม่ใช่หลังจากนั้น · ยังไม่ได้เลือกจะขึ้น "ยังไม่ได้เลือก"
ไม่เดาชื่อขึ้นมาเอง

## 3. ที่ **ไม่** แก้ และเหตุผล

**หน้าแก้ไขสินค้า → แท็บคอมมิชชั่น** และ **แบรนด์/หมวดหมู่ในแคตตาล็อก**
ไม่ต้องแก้ เพราะสองที่นี้แก้ไข **ในแถวของตัวเอง** (`editingRuleId === r.id`
เรนเดอร์ฟอร์มแทนที่เนื้อแถวนั้น) — ความกำกวมไม่เกิดตั้งแต่แรก
**เป็นแบบแผนที่ถูกต้องอยู่แล้ว และเป็นเหตุผลว่าทำไมหน้าแผนคอมมิชชั่นถึงสับสน**
เพราะมันเป็นที่เดียวที่ฟอร์มลอยอยู่คนละที่กับแถว

ฟอร์มตั้งค่าที่มีใบเดียวต่อบริษัท (Binary, Matrix settings, รอบคำนวณอันดับ,
Generation settings, Affiliate) ไม่ต้องมีหัวข้อ "ตัวไหน" — เพราะมีตัวเดียว
