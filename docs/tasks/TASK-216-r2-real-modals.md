# TASK-216 r2 — ฟอร์มแก้ไขกลายเป็น Modal จริง พื้นหลังดำ + หัวข้อ H1

**Status:** implemented + verified in browser (2026-08-20) · **Owner:** ag-lead
**คำขอ:** human — "ทำไมไม่เป็น modal backgroud สีดำ มีข้อความสำหรับแก้ไข หรือเพิ่ม และปรับตัวหนังสือ หัวข้อสินค้าเป็น H1"

---

## 1. เปลี่ยนอะไร

r1 เพิ่มแค่หัวข้อบนฟอร์มที่ยังเป็น inline — บรรเทาอาการ แต่ไม่แก้ที่ต้นเหตุ
ซึ่งก็คือ **ฟอร์มเปิดคนละที่กับแถวที่กด** r2 แก้ตรงนั้น

**ฟอร์ม 5 ตัวในหน้าแผนคอมมิชชั่นกลายเป็น modal เต็มรูปแบบ:**

| ฟอร์ม | เดิม | ใหม่ |
|---|---|---|
| อัตราค่าคอมตัวแทนผู้ขาย | inline บนสุดของหน้า | **modal** |
| อัตราค่าคอมหัวหน้าทีม | inline (การ์ดเหลือง) | **modal** |
| อัตรารายชั้น (Matrix) | inline | **modal** |
| ขั้นอันดับ (Stairstep) | inline | **modal** |
| อัตราราย Generation | inline | **modal** |

**โครงหัวข้อในทุก modal**

```
แก้ไขอัตราค่าคอมตัวแทนผู้ขาย                              ← บรรทัดเล็ก บอกว่ากำลังทำอะไร
สินค้า: Vital Blueprint Mini + BALANZ V5 Health Tracker   ← H1 บอกว่ากับตัวไหน   [✕]
```

- คำว่า **เพิ่ม / แก้ไข** สลับตามสถานะจริง ไม่ได้เขียนตายตัว
- ชื่อเป้าหมายเป็น **`<h1>` ขนาด `text-xl`** ตามที่ขอ
- บรรทัดเล็กใช้สีตามชนิดของเงิน — **น้ำเงิน = ตัวแทนผู้ขาย · เหลือง = หัวหน้าทีม**
  สีเดียวกับป้ายในรายการด้านหลัง

**พฤติกรรม modal**

- พื้นหลัง **`bg-black/60` เต็มจอ** (แบบเดียวกับ modal แบรนด์/หมวดหมู่ที่ใช้อยู่แล้ว)
- ปิดได้ 3 ทาง: ปุ่ม **✕** มุมขวาบน · ปุ่ม **ยกเลิก** · **คลิกพื้นหลัง**
- ขนาด **70% ของความกว้าง × 60% ของความสูงหน้าจอ** (`w-[70vw]` / `h-[60vh]`
  พร้อม `min-w-[320px]` กันแคบเกินบนจอเล็ก)
  · ยืนยันด้วย JS แล้ว: **1792 × 791** จาก viewport 2560 × 1318 = **70% / 60%** พอดี

### โครงสร้างการ์ด (ทำพร้อมกับการกำหนดความสูง)

พอความสูงถูกตรึงไว้ที่ 60% เนื้อหาที่สั้นกว่านั้นจะทิ้งพื้นที่ว่างใต้ปุ่ม
และเนื้อหาที่ยาวกว่าจะดันปุ่มหลุดจอ การ์ดจึงถูกจัดเป็น 3 ส่วน:

```
┌ header  (shrink-0)  ← หัวข้อ + H1 + ปุ่ม ✕   อยู่กับที่เสมอ
│ body    (flex-1 min-h-0 overflow-y-auto)     ← เลื่อนเฉพาะส่วนนี้
└ footer  (shrink-0)  ← ยกเลิก / บันทึก        ติดขอบล่างเสมอ
```

- ลอง `sticky bottom-0` ก่อนแล้ว **ใช้ไม่ได้** — sticky จะตรึงก็ต่อเมื่อเนื้อหา
  ล้นเท่านั้น เนื้อหาสั้นกว่าการ์ดจึงยังลอยอยู่กลางการ์ดเหมือนเดิม ต้องใช้
  flex column + `flex-1` ถึงจะได้ผลทุกกรณี
- ฟอร์มที่เป็น grid เพิ่ม `content-start` เพราะการ์ดสูงคงที่ทำให้แถวของ grid
  ยืดเต็มความสูง — เดิมตอนเป็น inline ปัญหานี้ไม่มี
- `overflow-y-auto` ที่ตัว overlay ทำให้ฟอร์มยาว ๆ เลื่อนได้บนจอเตี้ย

## 2. เพิ่มปุ่ม "ยกเลิก" ให้ 2 ฟอร์มที่ไม่เคยมี

ฟอร์ม **Matrix รายชั้น** และ **Generation** เดิมมีแค่ปุ่ม บันทึก ปุ่มเดียว
ตอนเป็น inline ยังพอทำเนา (เลื่อนหนีได้) แต่ **พอเป็น modal จะกลายเป็นกับดัก** —
ทางออกเดียวคือปุ่ม ✕ จึงเพิ่ม ยกเลิก ให้ทั้งสองพร้อมกับการแปลง

## 4. ที่ไม่แตะ

ฟอร์มตั้งค่าที่มี **ใบเดียวต่อบริษัท** (Binary, Matrix settings, รอบคำนวณอันดับ,
Generation settings, Affiliate) ยังเป็น inline เหมือนเดิม — ไม่ได้เปิดจากการกด
"แก้ไข" ที่แถวไหน ไม่มีคำถามว่า "กำลังแก้ตัวไหน" และการยัดเข้า modal จะทำให้
ต้องกดเปิดเพิ่มอีกขั้นโดยไม่ได้อะไรกลับมา

หน้าแก้ไขสินค้าและแบรนด์/หมวดหมู่ก็ไม่แตะ — แก้ไขในแถวตัวเองอยู่แล้ว (ดู r1 §3)
