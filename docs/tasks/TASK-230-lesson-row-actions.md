## 4. สิ่งที่ทำ

### 4.1 ปุ่มในแถว (`AcademyManagementView.vue`)

```html
<span :class="isLessonSelected(l) ? 'visible' : 'invisible group-hover:visible group-focus-within:visible'">
  <button @click.stop="startEditLessonFromOutline(m, l)"> ✏️ </button>
  <button @click.stop="requestDeleteLesson(l)">           🗑️ </button>
</span>
```

**สามจุดที่ตั้งใจ:**

1. **`group-focus-within:visible`** — ถ้ามีแค่ `group-hover` ปุ่มจะ **focus ด้วย Tab ได้แต่มองไม่เห็น**
   ซึ่งแย่กว่าไม่มีปุ่มเลย
2. **`.stop` ทั้งสองปุ่ม** — แถวเป็น click target ที่ทำหน้าที่ *เลือก* ถ้าไม่มี `.stop`
   กดลบจะเลือกแถวที่กำลังจะหายไปด้วย ไม่มี error ให้เห็น แต่ inspector จะค้างแสดงบทเรียนที่ถูกลบแล้ว
3. **แถวที่ถูกเลือกแสดงปุ่มถาวร** — จอสัมผัสไม่มี hover นี่คือทางเดียวที่แท็บเล็ตในโหมดกว้างเข้าถึงได้

### 4.2 ยืนยันก่อนลบ

**เดิมไม่มีเลย** — `deleteLesson` ยิง `api.delete` ตรงจากการคลิก ลบทั้งบทเรียนและความคืบหน้าของผู้เรียน
ทั้งที่ **ลบ Section ซึ่งความเสียหายใหญ่กว่า มียืนยันมาตั้งแต่ TASK-066**

ที่ผ่านมารอดมาได้เพราะปุ่มถูกซ่อนอยู่ในการ์ดที่ต้องเลือกบทเรียนก่อน
**การย้ายปุ่มมาไว้ทุกแถวคือการถอดเกราะบังเอิญอันนั้นออกพอดี** — ยืนยันจึงต้องมาพร้อมกันในงานเดียว
ถ้าปล่อยปุ่มที่กดง่ายขึ้นออกไปก่อนแล้วค่อยตามใส่ยืนยัน = ปล่อย regression ออกไปก่อน

ข้อความเตือน**ผูกกับบทเรียนนั้นจริง ๆ** ไม่ใช่ประโยคตายตัว:

| สถานะบทเรียน | ข้อความ |
|---|---|
| เผยแพร่แล้ว + มีแบบทดสอบ 12 ข้อ | ระบุชื่อ · "พร้อมแบบทดสอบ 12 คำถาม" · "ความคืบหน้าของผู้เรียนทุกคนในบทนี้จะถูกลบไปด้วย" |
| ฉบับร่าง ไม่มีแบบทดสอบ | ระบุชื่อ · "บทเรียนนี้ยังเป็นฉบับร่าง ผู้เรียนจึงยังไม่เห็น" |

คำเตือนที่แยกสองกรณีนี้ไม่ออก จะสอนให้ admin กดผ่านโดยไม่อ่าน

### 4.3 เก็บรายละเอียด

`confirmDeleteLesson()` เคลียร์ `selectedLessonId` / `editingLessonId` ถ้าตรงกับบทที่ลบ
ไม่งั้น inspector จะเรนเดอร์บทเรียนที่ไม่มีอยู่แล้วจนกว่าจะคลิกที่อื่น

## 5. เทสต์ที่เพิ่ม — 11 ตัว (26 ในไฟล์นี้, รวมทั้งแอป 117)

| กลุ่ม | ยืนยันอะไร |
|---|---|
| ปุ่มมีอยู่ตั้งแต่ render แรก | ไม่ต้องเลือกอะไรก่อน |
| `invisible` + `group-hover:visible` + `group-focus-within:visible` | **ยืนยันผ่าน class ไม่ใช่แค่ `exists()`** — การลบ utility ทิ้งจะได้ปุ่มที่อยู่ใน DOM ผ่านทุก exists() แต่กดไม่ได้ตลอดกาล |
| แถวที่เลือก = `visible` ถาวร | ทางเดียวของจอสัมผัส |
| คลิกแล้วยังไม่ลบ | `del` ต้องไม่ถูกเรียกจนกว่าจะกดยืนยัน |
| ข้อความเตือน 2 กรณี | เผยแพร่แล้ว vs ฉบับร่าง ต้องพูดคนละอย่าง |
| `@click.stop` | หลังกดลบ inspector ต้องยังเป็น empty state ไม่ใช่การ์ดของบทที่กำลังจะถูกลบ |
| จอแคบ | ปุ่มบนการ์ดยังอยู่ และ**ยืนยันก่อนลบเหมือนกัน** |
| จอกว้าง | ปุ่มบนการ์ดหายไป — ไม่มีทางเห็นปุ่มลบสองชุดในจอเดียว |
