## 3. บั๊กเก่าที่แก้ไปด้วย

### 3.1 ลบลิงก์พันธมิตร = ลบประวัติคลิกทิ้ง

`AffiliateLinkController::destroy()` เรียก `->delete()` และ `affiliate_link_clicks.link_id` เป็น `cascadeOnDelete`

**ตัวแทนกด "ยกเลิกลิงก์" = ลบทุกคลิกที่ลิงก์นั้นเคยบันทึกไว้ทิ้ง** และมันคือ**ตารางคลิกจริงตารางเดียวในระบบ**
(อีก 5 ชนิดมีแค่ตัวนับหรือไม่มีอะไรเลย) รายงานของบริษัทเปลี่ยนรูปไปเงียบ ๆ โดยไม่มีอะไรเตือน

และมันเป็น**ตารางเดียวใน 6 ตารางที่ hard delete** — อีก 5 ตัวใช้ `revoked_at` มาตลอด แก้แล้ว endpoint/verb/204 เหมือนเดิม

### 3.2 ตัวนับที่เขียนมาตลอดแต่ไม่มีใครเคยเห็น

`product_share_links.view_count` ถูก `increment()` ทุกครั้งที่มีคนเปิดหน้า ตั้งแต่ TASK-056
**และไม่มีหน้าจอไหนในทั้งสองแอปอ่านมันเลย** เก็บตัวเลขมาเปล่า ๆ ตลอด

ตอนนี้แสดงเป็น `legacy_view_count` **แยกจาก `click_count` ไม่บวกรวมกัน** เพราะสองตัวนับคนละอย่างคนละช่วงเวลา
(ตัวเก่านับตั้งแต่สร้างลิงก์และรวมบอททุกตัว ตัวใหม่เริ่มตอนมีรหัสสั้นและนับเฉพาะเบราว์เซอร์จริง) บวกกันจะได้เลขที่ไม่จริงสักอย่าง

## 4. การตัดสินใจที่สำคัญและเหตุผล

**รหัสตัด `0 O o 1 l I` ออก** — รหัสถูกอ่านจากกระดาษ ใบปลิว นามบัตร หรือคำบรรยายใต้ QR ที่สแกนไม่ติด
ทุกตัวใน 6 ตัวนี้คือ ticket ที่เขียนว่า "ลิงก์ใช้ไม่ได้" จากคนที่พิมพ์ถูกแล้วเท่าที่เขารู้ · 56^10 ≈ 3.0×10¹⁷ ยังเหลือเฟือ

**ลิงก์ชำระเงิน 14 ตัว ไม่ใช่ 10** — หน้านั้นเปิดดูรายการและยอดของออเดอร์ได้ และเดิมมี token 40 ตัวคุ้มอยู่
การเอาประตูหน้าที่สั้นกว่ามาใส่กับลิงก์เดียวที่เกี่ยวกับเงิน = **ลดการป้องกันลงเพื่อแลกความสะดวก**

**ไม่ทำ `/{code}` แบบไม่มีตัวคั่น** — แอปนี้มีหน้าจริงที่ระดับบนสุด (`/login`, `/products`, `/profile`, `/my-team`)
ถ้าไม่มีตัวคั่น วันที่ใครเพิ่มหน้าใหม่ที่ชื่อตรงกับรหัสของลูกค้าคนหนึ่ง ลิงก์คนนั้นตายทันที
และไม่มีอะไรในโค้ดที่เชื่อมสองเหตุการณ์นั้นเข้าด้วยกัน · เพิ่ม `admin` `api` `assets` เป็นคำสงวนด้วย

**✅ บอทพรีวิวไม่ปนเข้ามาเอง** — การนับเกิดตอนหน้าเว็บเรียก API และ **LINE/Facebook ไม่รัน JavaScript**
มันดึงแค่ HTML แล้วจบ **ไม่ใช่การกรองทีหลัง แต่นับไม่ถึงตั้งแต่แรก**
แบบที่เราไม่ได้ทำ (โดเมนใหม่ + redirect) จะต้องมีลิสต์ User-Agent ของบอทให้ตามอัปเดตตลอดไป

**อัตราแปลงหารด้วย "คนไม่ซ้ำ" ไม่ใช่ "เปิดทั้งหมด"** — คนที่อ่านหน้า 4 รอบก่อนซื้อคือ **1 คนที่ซื้อ**
หารด้วย 4 จะบอกว่าลิงก์แย่กว่าความจริง 4 เท่า และตัวแทนใช้เลขนี้ตัดสินว่าจะลงแรงตรงไหน

**ยังไม่มีคนเปิด = `null` ไม่ใช่ `0%`** — "0%" อ่านว่า *ลิงก์นี้ล้มเหลว* · "—" อ่านว่า *ยังไม่มีใครดู*
สองอันนี้ทำให้ตัวแทนลงมือคนละอย่างกันเลย

**อันดับตัวแทนเรียงตาม "ผลลัพธ์" ไม่ใช่ "คลิก"** — คนที่แชร์บ่อยที่สุดกับคนที่ได้ผลที่สุดมักไม่ใช่คนเดียวกัน
และมีแค่คนที่สองที่ควรเรียนรู้จาก

**ไม่มีทางลบ tracked link** — ไม่มี route ไม่มี policy method ลบแล้ว visit rows หายตาม (cascade)
และ attribution บนออเดอร์/ตัวแทนกลายเป็น null — คือความพังแบบเดียวกับข้อ 3.1 เป๊ะ

   **เจอบั๊ก 3 ตัวที่เทสต์อัตโนมัติจับไม่ได้เลย แก้ครบทั้ง 3** → `UAT-RESULT-links.md`
   ยังเหลือ `/j/` `/pay/` `/l/` `/m/` ที่ยังไม่ได้คลิก และ **ยังไม่เคยเห็นตัวเลข conversion ขยับจาก 0**
2. **มี migration 5 ตัว** — `tracked_links`, `tracked_link_visits`, `company_invite_codes` (แก้), `tracked_link_id` × 3 ตาราง, `affiliate_links.revoked_at`
   ต่างจากรอบก่อนที่ไม่มี migration เลย **ควร backup ฐานข้อมูลก่อน**
3. **ไม่ backfill รหัสสั้นให้ลิงก์เก่า** — ตั้งใจ เพราะรหัสใหม่จะไม่ใช่รหัสที่คนถืออยู่
   `short_url` เป็น null และทุกหน้าจอถอยไปใช้ลิงก์ยาว ซึ่งเป็นสิ่งที่ลูกค้ามีอยู่แล้วจริง ๆ
   **แก้จากเอกสารเดิม (UAT บั๊ก #3):** ลิงก์แชร์สินค้าที่มีอยู่แล้ว **จะได้รหัสสั้นตอนตัวแทนกดแชร์ซ้ำ**
   ไม่ใช่เฉพาะลิงก์ที่เพิ่งสร้าง — เดิมโค้ดสร้างรหัสอยู่หลัง early return ของ `ProductShareLinkService`
   จึงไม่มีวันทำงานกับสินค้าที่เคยแชร์แล้ว ซึ่งบนฐานข้อมูลจริงคือกรณีส่วนใหญ่ ลิงก์ยาวเดิมยังใช้ได้เหมือนเดิม
4. **`used_count` ของลิงก์สมัครบริษัทไม่มี lock** — เส้นทางนั้นไม่เปิด transaction เลยมาแต่เดิม
   (เอกสารเดิมยอมรับข้อจำกัดเดียวกันไว้แล้วเรื่องเอกสารซ้ำ) สองคนกดที่นั่งสุดท้ายพร้อมกันเข้าได้ทั้งคู่
   **เขียนไว้ในโค้ดตรงจุดนั้นแล้ว** — ควรแก้แยกต่างหากพร้อมย้าย document check เข้า transaction เดียวกัน
5. **ยังไม่มี QR ในหน้าลิงก์ใหม่** — `qrCode.ts` มีอยู่แล้วและหน้าธีมใช้อยู่ แต่ผมยังไม่ต่อเข้ากับ 3 หน้าใหม่
6. **ยังไม่ได้ทำเรื่อง PDPA** — เก็บ referrer host + user agent + ip hash ควรมีข้อความในนโยบายความเป็นส่วนตัว
   ผมไม่ใช่นักกฎหมายและไม่ควรตัดสินแทน
7. **ตาราง `tracked_link_visits` ไม่มีแผน archive** — วาง index ไว้แล้วและออกแบบให้ archive ได้ แต่ยังไม่ได้ทำ
