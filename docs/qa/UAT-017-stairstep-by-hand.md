## §0 ขอบเขต และสิ่งที่ต้องรู้ก่อนเริ่ม

**ทดสอบ:** บริษัทใหม่ 1 บริษัท · แผนอันดับ (Stairstep) · ทีม 4 คนต่อกันเป็นสาย · การขายที่ปิดจริง 9 ดีล · 2 วัน

**ต่างจาก UAT ชุดเดิมตรงไหน:** ชุดเดิม (`uat:seed-commission-plans`) สร้างข้อมูลด้วยคำสั่ง ส่วนชุดนี้ **คุณกรอกเองทุกอย่างผ่านหน้าจอ** ตั้งแต่ตั้งค่าคอม สมัครสมาชิกผ่านลิงก์หัวหน้า ไปจนถึงปิดการขาย มีแค่ 2 อย่างที่หน้าจอทำแทนไม่ได้:

1. **การจัดขั้น** — ไม่มีหน้าจอไหนตั้งขั้นให้ตัวแทนได้ ระบบคำนวณจากยอดขายวันละรอบ คุณจะสั่งรอบคำนวณเองด้วยคำสั่งใน Terminal (§6 และ §8)
2. **การรอข้ามวัน** — รอบคำนวณของบริษัทที่ตั้ง "รายวัน" รันซ้ำได้หลังผ่านไป 24 ชั่วโมงเท่านั้น

**ตัวเลขทุกตัวในเอกสารนี้ไม่ได้คิดด้วยมือ** — มาจากเทสต์ `tests/Feature/Uat/Uat017StairstepByHandTest.php` ที่เดินขั้นตอนเดียวกันนี้ผ่าน API ทุกขั้น ถ้าหน้าจอแสดงไม่ตรง แปลว่าเจอของจริง ไม่ใช่ตัวเลขในเอกสารผิด

> **ค่าทุกค่าในเอกสารนี้เป็นค่าสำหรับทดสอบเท่านั้น** (อัตรา ยอดขั้นต่ำ ราคา) เลือกให้คิดในใจได้ง่าย **ไม่ใช่ค่าที่แนะนำให้บริษัทจริงใช้** (BR-7)

## §0.5 ก่อนเริ่ม — ทำใน Terminal บน Mac ของคุณ

ทุกคำสั่งรันจากโฟลเดอร์โปรเจกต์ มันอ่านค่าเชื่อมต่อจาก `.env.deploy` ของคุณเอง คุณไม่ต้องพิมพ์รหัสผ่านหรือคีย์ใด ๆ

### 0.5.1 ☐ Deploy ขึ้น production ก่อน

UAT ชุดนี้ทดสอบของที่เพิ่งแก้วันนี้ 3 อย่าง ถ้ายังไม่ deploy ขั้นที่ต้องผ่านจะไม่ผ่าน:

- ปิดช่องโหว่ที่ตัวแทนกดปิดการขายของตัวเองได้ (ADR-046)
- คอลัมน์ "ขั้นปัจจุบัน" ในหน้ารายชื่อสมาชิก
- คำสั่งคำนวณขั้นแบบเลือกบริษัทเดียว (`--company`)

commit ตามคำสั่งที่ ag-lead ให้ไว้ แล้วรัน `npm run deploy`

### 0.5.2 ☐ ล้าง UAT ชุดเดิมออก

```bash
cd /Applications/MAMP/htdocs/agent && source .env.deploy && ssh -t -p "$SSH_PORT" ${SSH_KEY_PATH:+-i "$SSH_KEY_PATH"} "$SSH_USER@$SSH_HOST" "cd '$BACKEND_REMOTE_PATH' && ${PHP_BIN:-php} artisan uat:purge-commission-plans"
```

- **สิ่งที่ถูกลบ:** เฉพาะบริษัทที่ slug ขึ้นต้นด้วย `uat-plan-` และทุกอย่างใต้บริษัทนั้น (คือ 6 บริษัท `UAT · Unilevel` … `UAT · Affiliate`)
- **ไม่แตะ:** บริษัทจริงทุกบริษัท
- คำสั่งจะแสดงรายชื่อบริษัทและจำนวนแถวก่อนลบ แล้วให้พิมพ์ `PURGE UAT` เพื่อยืนยัน
- ☐ อ่านรายชื่อให้ครบก่อนพิมพ์ ทุกบรรทัดต้องขึ้นต้นด้วย `uat-plan-`
- บัญชีตัวแทน UAT ชุดเดิม (อีเมล `…@uat.invalid`) จะเหลือค้างโดยไม่มีบริษัท คำสั่งจะบอกจำนวน ลบทิ้งจากหน้าจัดการผู้ใช้ได้ถ้าต้องการ

### 0.5.3 ☐ (อ่านอย่างเดียว) ระบบคำนวณขั้นอัตโนมัติรันอยู่จริงไหม

```bash
cd /Applications/MAMP/htdocs/agent && source .env.deploy && ssh -p "$SSH_PORT" ${SSH_KEY_PATH:+-i "$SSH_KEY_PATH"} "$SSH_USER@$SSH_HOST" "crontab -l 2>/dev/null | grep -i 'schedule:run' || echo 'NOT FOUND in crontab'; cd '$BACKEND_REMOTE_PATH' && ${PHP_BIN:-php} artisan schedule:list 2>/dev/null | grep -i rank"
```

- UAT ชุดนี้ไม่ต้องใช้ระบบอัตโนมัติ เพราะคุณสั่งคำนวณเอง แต่ **บริษัทจริงที่ใช้แผนอันดับต้องพึ่งมัน**
- ถ้าเห็น `NOT FOUND in crontab` ให้ไปดูที่ hPanel → Advanced → Cron Jobs ด้วย (Hostinger อาจเก็บไว้ที่นั่น)
- ถ้าที่ hPanel ก็ไม่มี แปลว่า **ไม่มีบริษัทไหนเคยได้ขั้นอัตโนมัติเลย** ให้แจ้ง ag-lead เป็นเรื่องแยกจาก UAT นี้

### 1.3 สินค้า 1 ตัว

`UAT แพ็กเกจ ฿10,000` · ราคา **10,000 บาท** · เส้นทางการขาย **ขายตรง** (ค่าเริ่มต้นของสินค้าใหม่ ไม่ต้องเปลี่ยน)

### 1.4 ทีม 4 คน ต่อกันเป็นสายเดียว

```
ผู้อำนวยการ (D)  ←  ผู้จัดการ (M)  ←  ผู้นำ (L)  ←  ผู้ขาย (S)
    บนสุด                                            ล่างสุด
```

| คนที่ | ชื่อ (ช่องชื่อ / นามสกุล) | สมัครผ่าน | ใครอนุมัติ |
|---|---|---|---|
| D | `UAT` / `ผู้อำนวยการ` | ลิงก์สมัครของบริษัท | คุณ (แอดมิน) |
| M | `UAT` / `ผู้จัดการ` | ลิงก์ชวนเข้าทีมของ D | D (ในพอร์ทัล) |
| L | `UAT` / `ผู้นำ` | ลิงก์ชวนเข้าทีมของ M | M (ในพอร์ทัล) |
| S | `UAT` / `ผู้ขาย` | ลิงก์ชวนเข้าทีมของ L | L (ในพอร์ทัล) |

**อีเมล:** ใช้อีเมล Gmail ของคุณเองแล้วเติม `+ป้าย` หน้า `@` เช่น `ชื่อคุณ+uat-d@gmail.com`, `ชื่อคุณ+uat-m@gmail.com` อีเมลยืนยันทั้ง 4 ฉบับจะเข้ากล่องเดียวกันของคุณ แต่ระบบนับเป็น 4 บัญชี

**เบราว์เซอร์:** พอร์ทัลจำการล็อกอินไว้ต่อเบราว์เซอร์ ให้ใช้ **หน้าต่างส่วนตัว (Incognito) หรือ Chrome Profile แยก 1 อันต่อ 1 คน** ไม่งั้นการเปิดลิงก์สมัครจะชนกับคนที่ล็อกอินอยู่
